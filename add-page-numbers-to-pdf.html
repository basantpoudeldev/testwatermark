Add page numbers to a PDF

Pick a corner, a number format, and a starting page — Proofmark stamps every page automatically.

Try it now — free, and nothing you upload leaves your browser.

Add page numbers now

Adding page numbers by hand, page by page, is tedious for anything longer than a few pages. Proofmark does it in one pass: choose a corner position, a format (plain number, "Page N", "N / total", or "Page N of total"), where numbering should start, and the size and color — then every page in the document gets numbered automatically.

Frequently asked questions

Can numbering start from something other than 1?

Yes — set any starting number, useful for documents that continue from a previous section.

Can I number multiple PDFs at once?

Yes — upload several files and each gets numbered independently, bundled into a ZIP.
