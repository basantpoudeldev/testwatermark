Shrink a PDF's file size, mainly by recompressing the photos embedded inside it.

Compress a PDF now

Most of a PDF's file size usually comes from embedded images rather than the text itself. Proofmark's PDF compressor finds JPEG images inside your PDF and recompresses them at a lower quality, which can meaningfully shrink photo-heavy documents like scanned booklets or image-heavy reports.

Set honest expectations

This won't match the compression ratios of professional desktop tools on every file. Text-heavy or already-optimized PDFs will shrink only modestly, since there isn't much image data to recompress. It works best on PDFs with multiple embedded photos.

Frequently asked questions

Will this reduce text quality?

No — text and vector graphics in the PDF are untouched. Only embedded JPEG images are recompressed.

Does this work on scanned documents?

Yes, often very effectively — a scanned page is typically one large embedded image per page, which is exactly what this tool targets.

What if a PDF barely shrinks?

That usually means the file doesn't contain much recompressible image data to begin with — for example, a mostly-text PDF or one using image formats other than JPEG.
