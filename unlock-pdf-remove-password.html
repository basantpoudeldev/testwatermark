Unlock a PDF now

If you have a password-protected PDF and know the password, Proofmark can strip that protection out entirely so the file opens freely from then on — useful for documents you've received that no longer need to stay locked, or your own files where re-entering a password every time has become more hassle than it's worth.

This is not a password cracker

This tool requires the correct password to work — it removes protection you already have legitimate access to, the same way "remove password" works in Adobe Acrobat or similar tools. It does not attempt to guess, brute-force, or bypass a password you don't know.

What encryption is supported

Both encryption types PDFs commonly use are supported and auto-detected: modern AES-256 (used by newer PDF software) and legacy RC4 (used by older PDF software, including files Proofmark's own Protect tool creates).

Frequently asked questions

What if I enter the wrong password?

Decryption fails cleanly with an error — it won't produce a corrupted or partially-unlocked file.

Does this work on any password-protected PDF?

It covers the two standard PDF encryption methods (AES-256 and RC4) that the vast majority of password-protected PDFs use.

Is this different from Proofmark's Protect PDF tool?

Protect PDF adds a password; this tool removes one you already know — they're inverse operations.
